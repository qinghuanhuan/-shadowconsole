# 卷影管理台 · VSS Shadow Console

Windows 卷影副本（VSS 快照）桌面管理工具。单文件分发、双击即用；快照的查看、创建、删除、配额管理、定时计划全部图形化操作，无需命令行。

> 图形界面基于 **.NET WPF**（XAML）构建，由 PowerShell 5.1 脚本宿主承载——无需编译即可运行，界面定义与渲染逻辑即为源码，可直接阅读修改。

> **10 秒上手**：下载 → 双击 → UAC 点「是」→ 使用。

## 核心特性

### 性能

界面响应经过多轮专项优化：采用**持久化位图缓存**，动画与状态变化不触发整窗重绘，垃圾回收低延迟调度，多轮审查避免周期性卡顿。除启动初始化（PowerShell 引擎加载约 3 秒）外，操作丝滑流畅——**加载动画期间界面可操作，无需等待**。

### 功能覆盖

覆盖桌面 Windows 用户可用的全部 VSS 能力：快照查看 / 创建 / 删除、配额调整、定时计划、快照浏览、系统状态。**仅未处理「指定存储位置」一项**（桌面系统支持该能力，未规划，个人觉得无用）；其余未覆盖项均为 Windows Server 或 SAN 硬件专属能力，桌面端不支持。

### 分发与卫生

单文件分发（约 200 KB），无外部依赖、无配置文件。运行时临时文件统一存放于 `%TEMP%\shadowconsole\`，**各日志文件保留最近 500 条**，不残留、不污染系统。

### 透明可审查

脚本文件即源码，用任意文本编辑器可完整审查，欢迎完善修改；内置命令日志实时展示每次操作的真实命令行、退出码与输出。

### 可定制

程序完全由 AI 编写，完全支持个性化修改，在AI能力范围内。

## 10 秒上手

1. **下载** `卷影管理台.bat`（约 200 KB，无任何外部依赖）
2. **运行**：双击，CMD窗后弹出Powershell窗，之后 UAC 弹窗点「是」
3. **使用**：左侧导航切换页面；**双击/右键** 快照行 即可在资源管理器中浏览该时间点的文件内容

> 拒绝 UAC 可进入**只读模式**：无需权限的数据可查看，写操作自动禁用（左上角可随时以管理员身份重启）杜绝必须给权限的流氓行为。

## 详细使用

### 1. 卷影副本页

- 上半区为**磁盘卷卡片**：容量、已用比例、卷影数量；点击选中（再点取消）
- 选中卷后可操作：**创建卷影 / 删除最旧 / 全部删除**（均有确认提示）
- 下半区为快照列表：创建时间、卷、阴影 ID、设备对象、属性
- **双击快照行**（或右键"打开浏览"）→ 资源管理器打开快照内容
- 右键"复制设备路径"可复制 `\\?\GLOBALROOT\Device\HarddiskVolumeShadowCopyN` 形式路径

### 2. 存储配额页

- 每个固定磁盘一行：已用空间、已分配、上限、占用比例、存储位置
- 未设置配额的卷显示"未设置"，点"调整"可首次创建
- 自动上限按（空闲空间 + 卷影占用）比例计算；达到上限后系统自动淘汰最旧快照

### 3. 计划任务页

左侧任务列表，右侧编辑表单：

| 设置项 | 说明 |
| --- | --- |
| 任务名称 | 自动加 `ShadowConsole-` 前缀，注册于 任务计划程序 → `\ShadowConsole\` |
| 目标卷 | 选择要创建快照的磁盘 |
| 计划类型 | 按分钟 / 按小时 / 每天 / 每周 / 每月 |
| 执行时间 | 每天/每周/每月：`HH:mm`，多时间点逗号分隔（如 `09:00,14:00,18:00`） |
| 重复间隔 | 按分钟/按小时：输入间隔，全天循环 |
| 每周 | 点选周几 |
| 每月 | 日期 1-31（选 31 = 每月最后一天） |
| 描述 | 备注信息 |
| 错过补跑 | 开机错过的任务下次开机补执行 |

操作：未选中任务时仅「新建任务」；点击任务进入编辑（再点取消选中）；选中后可 保存 / 导出 XML / 立即运行 / 启用禁用 / 删除。

### 4. 命令日志页

- 所有查询与操作的真实命令：时间、工具、参数、退出码、耗时
- 点击行查看完整输出；保留最新 500 条，自动淘汰最旧，新记录不丢失
- 可复制完整输出

### 5. 系统信息页

提供程序列表（名称 / 类型 / 版本 / ID）、写入程序列表（状态 / 名称 / ID / 实例 / 上次错误）及原始输出——排查 VSS 健康状态。

## 设置与配置

- **设置存储**：程序文件自身（尾部配置区），零外部配置文件——拷贝文件，设置随行
- **自动保存**：窗口位置/大小、左栏宽、当前页、主题、各表格列宽/排序/列顺序——操作停止 3 秒自动保存，关闭时兜底保存
- **恢复出厂**：删除文件尾部 `#===CONFIG-BEGIN===` 至 `#===CONFIG-END===` 之间的内容

## 常见问题

**Q：双击 bat 后 UAC 同意，等待数秒无窗口？**  
临时文件位于 `%TEMP%\shadowconsole\`，提权进程延迟启动读取，属正常等待（约 3 秒）。仍无窗口时查看 `%TEMP%\shadowconsole\crash.log`。

**Q：创建快照失败提示"存储空间不足 / 已达上限"？**  
VSS 存在配额限制，请至"存储配额"页调整上限，或删除旧快照释放空间。

**Q：计划的快照未生效？**  
打开"任务计划程序"检查 `\ShadowConsole\` 下任务状态与上次运行结果；任务以 SYSTEM 身份运行，无需登录。

**Q：程序写自身文件（bat）不会损坏吗？**  
设置仅写入尾部 `#===CONFIG-BEGIN===` 与 `#===CONFIG-END===` 之间，不触碰代码区；写入失败静默跳过，不影响使用。

**Q：日志文件在哪里、保留多久？**  
`%TEMP%\shadowconsole\` 下，各日志文件保留最近 500 条自动截断；排查问题可查看 crash.log / disptex.log / taskerr.log。
